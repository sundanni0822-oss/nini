# 小托福单词学习系统

> 为家长打造的一站式单词学习管理工具：拍照上传词库 → 生成 A4 默写纸 → 批改记错题 → 艾宾浩斯复习 → 日历跟踪。
> 孩子：小学高年级（4-6年级），备考小托福（TOEFL Junior）。

## 快速开始
1. 用浏览器打开 `index.html`（双击文件，或通过本地服务器 `http://localhost:8080/`）
2. 顶部选择/添加孩子（支持多孩子，互不干扰）
3. **上传单词书照片**：到「词库」页上传书页照片 → 在聊天框把照片发给我 → 我识别后成为新的 DAY → 刷新页面
4. 到「默写纸」页：选「直接选 DAY / 单元」→ 选识别出的 DAY → 选方向 → 一键生成 A4，打印/存 PDF
5. 孩子默写后，到「批改」页上传照片逐词点对/错，错词自动进错题本
6. 错词按艾宾浩斯（第 1/3/7/15/30 天）自动出现在「孩子模式」默写纸复习区
7. 「日历」页随时查看每个孩子的每日完成情况

## 两种内容来源
- **直接选 DAY / 单元（推荐，简单）**：图片识别出的教材 DAY、小托福各级单元、家长上传词、今日计划，直接下拉选择即可生成，无需手动勾选
- **按当日计划**：在词库页勾选词保存为某天的计划，默写纸按计划日期取词

## 默写方向（3 种）
- 看英文写中文（红色）
- 看中文写英文（蓝色）
- **左右对照（一纸两测，中间对折）**：左栏看英文写中文，右栏看中文写英文，同一行左右对应

## 六大模块
1. **今日概览**：今日计划新词数 / 到期复习数 / 错题总数
2. **班级看板**：昨日打卡统计（缺卡红色提醒）、打卡排行榜、班级共性错词、各孩子正确率与易错词 Top
3. **词库**：上传书页照片 → 真实 OCR 识别（Tesseract.js）→ 核对保存为新 DAY；手动粘贴添加；当日计划管理；词库总览（全局统一）
4. **默写纸**：两种模式（统一进度 / 孩子模式）+ 三种方向，A4 一键打印
5. **批改**：上传默写纸照片，逐词点对/错，错词自动进错题本；复习区单独批改
6. **错题本**：错词列表 + 复习阶段 + 到期状态，可一键打印错题本
7. **日历**：每月完成情况可视化（全对/有错/未完成）

## 核心规则
- **词库全局统一**：家长上传一次，所有孩子同步可见
- **双模式默写纸**：
  - 统一进度 = 仅当日内容（DAY / 计划词）
  - 孩子模式 = 当日内容 + 该孩子到期复习错词（标注「复习第 N 天」，不占新词）
- **艾宾浩斯**：错词 1→3→7→15→30 天间隔复习；复习正确进入下一阶段，再错回到第 1 阶段
- **真实 OCR**：上传书页照片点「开始识别」，Tesseract.js 本地识别（首次需联网下载引擎），识别结果可编辑核对后保存
- **打卡看板**：提交批改 = 当天打卡；看板统计昨日打卡情况，缺卡自动提醒
- **数据本地存储**：全部存浏览器 localStorage，不联网、不注册；导出备份可自行操作（F12 → Application → Local Storage）

## 数据备份
1. 打开页面后按 F12 → Application → Local Storage → 当前网址
2. 复制 `vocabSystem_v1` 的值保存为文本文件即可备份
3. 需要恢复时用同样位置粘贴回去
